单证速录

上传合同与发票，自动分类并抓取公司、产品、金额、港口与日期，核对后一键复制。

本机处理 · 不联网 · 不上传

1需要准备的文件

合同类已录入 0 份

  • 销售合同 / 采购合同 (Sales / Purchase Contract)
  • 框架协议、补充协议
  • 抓取：合同编号、买卖双方、产品、数量、单价、总金额、装运港 / 目的港、装运与到港日期、付款方式

发票类已录入 0 份

  • 商业发票 Commercial Invoice
  • 形式发票 Proforma Invoice (PI)
  • 增值税专用 / 普通发票
  • 抓取：发票号码、开票日期、销售方 / 购买方、产品、金额、税额、到港日期

支持 PDF、Word (.docx)、Excel (.xlsx/.csv)、TXT，以及扫描件 / 照片 (JPG、PNG)。扫描件和照片用本机文字识别 (OCR)，速度较慢，结果请重点核对。

拖入文件，或点击选择 可一次多选，系统自动判断是合同还是发票
