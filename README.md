# 单证速录

> 合同 / 发票关键信息本地抓取工具：拖入文件，自动分类，抓取公司、产品、金额、港口与日期，核对后一键复制到 Excel。

**本机处理 · 不联网 · 不上传。** 所有解析、文字识别 (OCR) 和信息抓取都在你自己的浏览器里完成，不调用任何 AI 或云端接口。

## 功能概览

- **多格式录入**：PDF、Word (.docx)、Excel (.xlsx / .xls / .csv)、TXT、JPG / PNG / WebP 照片和扫描件，也可以直接粘贴文字。
- **批量处理**：一次可以拖入或多选多个文件。
- **自动分类**：根据文件名和正文关键词判断是 **合同**、**发票** 还是 **待分类**，判断错了可以手动改。
- **细分单据类型**：自动识别销售合同、采购合同、增值税发票、商业发票、形式发票 (PI)、开票通知。
- **关键字段抓取**：合同 16 个字段、发票 17 个字段，重点字段加粗显示（见[抓取字段](#抓取字段)）。
- **产品明细表**：识别增值税发票的明细行，以及“品名 / 数量 / 单价 / 金额”逐行重复的写法，自动汇总数量。
- **中英文混排**：支持中文标签和英文标签（如 `Invoice No.`、`Unit Price`、`Port of Loading`），日期支持 `2026年3月5日`、`2026-03-05`、`5th Mar 2026`、`March 5, 2026` 等写法。
- **扫描件 OCR**：内置 Tesseract 引擎和简体中文 + 英文识别模型，不用联网也能识别。
- **可编辑、可复制**：识别结果可以直接修改；可以复制单个字段、整张单据、产品明细表，或把当前分类的所有单据复制成表格粘贴到 Excel。
- **自动保存**：录入结果保存在本机浏览器的本地存储 (localStorage) 里，刷新或关闭页面后不会丢失。
- **深色模式**：跟随系统的深浅色设置。

## 隐私与安全

本工具用来处理合同和发票这类敏感文件，所以设计上不让任何数据离开你的电脑：

| 措施 | 说明 |
| --- | --- |
| 不联网 | 所有依赖库（PDF / Word / Excel 解析、OCR 引擎和识别模型）都放在 `lib/` 目录里，不从网上加载。 |
| 安全策略 (CSP) | 页面设置了 `Content-Security-Policy`，浏览器会禁止页面访问任何外部网址。 |
| 只监听本机 | `启动.bat` 启动的本地服务只绑定 `127.0.0.1`，局域网里的其他电脑访问不到。 |
| 本地存储 | 录入结果只保存在当前浏览器的 localStorage 里，不写到服务器，也不同步到云端。 |
| 无 AI 调用 | 信息抓取全部靠关键词规则，不把文件内容发给任何模型。 |

> 提示：在公用电脑上用完后，可以点“清空本类”删除已保存的记录。

## 快速开始

### 方式一：用启动脚本打开（推荐，功能完整）

1. 确认电脑上装有 [Python 3](https://www.python.org/downloads/)（安装时勾选 “Add Python to PATH”）。
2. 双击 **`启动.bat`**。
3. 浏览器会自动打开 <http://127.0.0.1:8765/>。
4. 用完后关闭那个黑色命令行窗口就行。

### 方式二：直接双击 `index.html`

不用安装任何东西就能打开。文字版的 PDF、Word、Excel、TXT 都能正常处理，但**扫描件和照片的 OCR 识别用不了**：浏览器在 `file://` 下会限制 OCR 需要的 Web Worker 和 WASM。

### 方式三：手动启动本地服务（macOS / Linux）

```bash
cd 单证速录
python3 -m http.server 8765 --bind 127.0.0.1
```

然后在浏览器里打开 <http://127.0.0.1:8765/>。

### 获取代码

```bash
git clone https://github.com/MiaoWeiXu/-.git 单证速录
```

也可以在 GitHub 页面点 **Code → Download ZIP** 下载，解压后使用。

## 使用流程

页面分成四步：

1. **需要准备的文件**：左侧列出合同类和发票类分别支持哪些单据、会抓取哪些信息，并显示每类已经录入了多少份。
2. **系统录入**：把文件拖进虚线框（或点击后选择），可以一次多选；也可以把文字粘贴到文本框里，然后点“录入粘贴内容”。
3. **识别结果**：按 **合同 / 发票 / 待分类** 三个标签页显示，每份单据一张卡片：
   - 右上角可以改文件类型；
   - 字段可以直接编辑，加粗的是重点字段；
   - “按当前分类重新抓取”会按改过的类型重新从原文抓取（**会覆盖手动修改**）。
4. **复制粘贴**：
   - 字段旁边的“复制”：只复制这一个字段；
   - “复制本单全部信息”：复制这份单据的全部字段；
   - “复制明细表（粘贴到 Excel）”：复制产品明细；
   - “复制为表格（粘贴到 Excel）”：把当前标签页的所有单据复制成一张表，每份单据一行；
   - “复制为文字”：复制成纯文本。

> 如果浏览器不允许自动写入剪贴板，页面会弹出一个文本框，按 `Ctrl+C`（手机上长按）手动复制即可。

## 支持的文件

| 格式 | 扩展名 | 处理方式 | 备注 |
| --- | --- | --- | --- |
| PDF（文字版） | `.pdf` | pdf.js 提取文字 | 效果最好；只读取前 15 页 |
| PDF（扫描版） | `.pdf` | 逐页渲染成图片后 OCR | 需要用方式一打开，速度较慢；只识别前 3 页 |
| Word | `.docx` | mammoth 提取文字 | **不支持旧版 `.doc`**，请另存为 `.docx` 或 PDF |
| Excel / 表格 | `.xlsx` `.xls` `.csv` | SheetJS 读取所有工作表 | |
| 纯文本 | `.txt` | 直接读取 | |
| 图片 | `.jpg` `.jpeg` `.png` `.webp` | Tesseract OCR（简体中文 + 英文） | 需要用方式一打开，务必人工核对 |
| 粘贴文字 | — | 直接处理 | 适合从邮件或网页复制的内容 |

**支持的单据类型**

- 合同类：销售合同、采购合同（Sales / Purchase Contract）、框架协议、补充协议
- 发票类：商业发票 (Commercial Invoice)、形式发票 (Proforma Invoice, PI)、增值税专用 / 普通发票、开票通知

## 抓取字段

**加粗**的是重点字段，卡片上会突出显示。

### 合同

| 字段 | 字段 |
| --- | --- |
| 合同编号 | 签订日期 |
| 签署地点 | **卖方 / 供货方（乙方）** |
| **买方 / 采购方（甲方）** | 最终用户 |
| **产品名称** | 数量 |
| 单价 | **合同总金额** |
| 币种 | 装运港 |
| 目的港 / 交货地点 | 装运日期 (ETD) |
| **到港 / 入港 / 交货日期** | 付款方式 |

### 发票

| 字段 | 字段 |
| --- | --- |
| 发票号码 | 开票 / 通知日期 |
| **销售方 / 开票方** | **购买方（发票抬头）** |
| 购买方税号 | 购买方地址电话 |
| 购买方开户行及账号 | 对应合同号 |
| **产品名称** | 数量合计 |
| 单价 | **发票总金额（价税合计）** |
| 币种 | 税额 |
| 装运港 | 目的港 |
| **到港 / 入港日期 (ETA)** | |

“待分类”的单据先按合同字段抓取，改成合同或发票后，可以点“按当前分类重新抓取”。

## 工作原理

```
文件 / 粘贴文字
      │
      ▼
 ┌──────────────┐   PDF → pdf.js（没有文字层时渲染成图片再 OCR）
 │  提取文字     │   DOCX → mammoth   XLSX/CSV → SheetJS
 │  readFile()  │   图片 → Tesseract.js（chi_sim + eng）
 └──────┬───────┘
        ▼
 ┌──────────────┐   文件名优先；再按正文关键词打分：
 │  自动分类     │   合同：合同 / 协议 / contract / 甲方 / 乙方 / 条款…
 │  classify()  │   发票：发票 / invoice / 税额 / 价税合计 / 开票…
 └──────┬───────┘
        ▼
 ┌──────────────┐   按标签就近匹配（中英文标签同义词表）
 │  规则抓取     │   日期、金额、币种、公司名、港口
 │localExtract()│   产品明细：增值税发票明细行 / “品名：数量：单价：”写法
 └──────┬───────┘
        ▼
  卡片展示 → 人工核对 / 修改 → 复制到 Excel
        │
        └─→ 自动保存到 localStorage（键名 danzheng.records.v1）
```

- **分类**：文件名里明确写了“合同 / contract / 协议”或“发票 / invoice”时，直接按文件名分类；否则读取正文前 6000 个字，按关键词出现次数加权打分，两边都没命中就归为“待分类”。
- **抓取**：完全基于规则，没有用 AI 模型。每个字段都有一组中英文标签同义词，程序在标签附近查找对应的值，再统一日期格式、清理金额。

## 常见问题

**双击 `启动.bat` 提示“没有找到 Python”？**
请安装 Python 3，安装时勾选 “Add Python to PATH”；或者先用方式二直接打开 `index.html`（不能做 OCR）。

**端口 8765 被占用？**
用记事本打开 `启动.bat`，把 `set PORT=8765` 改成别的端口，比如 `8766`。

**扫描件识别不出来或者乱码？**
- 确认是用 `启动.bat` 打开的（地址栏显示 `http://127.0.0.1:...`，而不是 `file:///...`）；
- 第一次识别要加载模型，会比较慢；
- 尽量用清晰、端正、分辨率高的扫描件，倾斜或模糊的照片误差会很大。

**`.doc` 文件打不开？**
不支持旧版 Word 格式，请在 Word 里另存为 `.docx` 或 PDF。

**换了浏览器 / 电脑后记录没了？**
记录保存在当前浏览器的本地存储里，不会跨浏览器或跨电脑同步。需要保留的数据请及时复制到 Excel。

**分类判断错了？**
在卡片右上角改类型，再点“按当前分类重新抓取”。

## 局限与注意事项

- 抓取靠的是关键词规则 + 本机 OCR，**格式规整的文字版文件效果最好**；版式特殊、标签写法少见的单据可能抓不全。
- 扫描件和照片的误差较大，**金额、日期、账号等关键信息务必人工核对**。
- 规则会尽量适配常见写法，但不能保证适用于所有公司的模板。
- 本工具只是辅助录入，不能替代对原始单据的审核。
